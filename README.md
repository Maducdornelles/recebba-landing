# Recebba Landing Page

Landing page independente do Recebba, pronta para rodar em Next.js e publicar na Vercel.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Build

```bash
npm run build
```

## Arquivos principais

- `components/landing/LandingPage.tsx` — conteúdo e estrutura da landing.
- `components/landing/landing.module.css` — todo o visual, responsividade, animações e mockups.
- `components/landing/Logo.tsx` — logo do Recebba.
- `public/screens/` — prints reais do produto usados na página.
